# beancount-utils
Miscellaneous utilities for working with the [beancount](https://github.com/beancount/beancount) text-file accounting system

## Development

Install dependencies and run the test suite with [pytest](https://docs.pytest.org/):

```sh
pip install -r requirements.txt
pytest
```

Tests live in [`tests/`](tests/) (configured via `testpaths` in `pyproject.toml`).
